# gruesomeparty/homebrew-tap

Homebrew tap for [gruesomeparty](https://github.com/gruesomeparty) tools.

```sh
brew install --cask gruesomeparty/tap/severance
```

[Severance](https://github.com/gruesomeparty/severance) — sever your side-project
Claude Code spend from your work spend. The app is ad-hoc signed; add
`--no-quarantine` if Gatekeeper blocks it.
